🧮 Multiplying is easy

Given two primes p and q, computing n = p · q is one step — whether the numbers have 2 digits or 600.

Example3 × 5 = 15
Real RSAone CPU multiply

🔒 Factoring is hard

Given only n, recovering p and q means searching divisor candidates one at a time.

To factor n = 15:
✗try 2 → 15 mod 2 = 1
✓try 3 → 15 / 3 = 5 → p=3, q=5
Real RSA uses ~1200-digit n. That's ≈ 10³⁰⁰ candidates to try — more steps than there have been seconds since the Big Bang (≈ 10¹⁷). Even the best known algorithms can't close that gap.
Candidates≈ 10³⁰⁰
Universe age≈ 10¹⁷ s

🪤 The one-way gap the trapdoor

Encryption uses only the public pair (n, e). Decryption requires d, which requires φ(n) = (p−1)(q−1), which requires the original primes. The key-holder takes a shortcut — everyone else has to factor n.

Any e with gcd(e, φ(n)) = 1. Usually small (65537).

Private d

Modular inverse of e mod φ(n): e · d ≡ 1.

📨 Encrypt using someone else's public key

In practice nobody shares secrets first — they just look up the recipient's public (n, e) and encrypt toward it. Only the owner of the matching d can read it.
